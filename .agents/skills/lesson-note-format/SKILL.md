# Lesson Note Format

當使用者要求建立課程筆記（lesson note 或課堂筆記）時，請依循以下步驟與格式規範建立 `.md` 檔案。

## 執行步驟

1. **確認當天實際日期**：
   取得目前的本地日期，並格式化為 `YYYY年MM月DD日`（例如：`2026年11月25日`，月份與日期固定為兩位數補零）。若不確定目前系統日期，請透過系統指令查詢，切勿憑空猜測或直接沿用範例日期。
2. **決定檔名與路徑**：
   依使用者指定的檔名或課程主題建立 `.md` 檔案。
3. **撰寫檔案內容**：
   在 `.md` 檔案的最開頭加上建立日期，接著撰寫課程標題與筆記內容。

## 檔案開頭格式

檔案開頭必須包含建立日期，格式如下：

```markdown
建立日期：YYYY年MM月DD日

# <課程名稱 / 筆記標題>

## 課程重點
- ...
```

### 日期格式範例
- 正確：`建立日期：2026年11月25日`
- 錯誤：`2026-11-25`、`2026/11/25`、`2026年5月3日`（應為 `2026年05月03日`）
